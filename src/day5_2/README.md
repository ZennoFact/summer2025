## マメ知識

- `FontMetrics` というクラスがあり，描画時の文字サイズを取得できる作りになっているが，FontMetricsクラスはあくまで「理論上の整数ベースのメトリクス」 のため，過信は禁物（OSの違いなど，環境ごとに実際の表示サイズがぶれるために起きる現象）
    - 今回のプログラムでは `FontRenderContext`　と　`StringBounds` を使って文字のセンタリングを実現している。
- `LocalDateTime.now()`で現在の時間を取得できる。昔は別クラスを使っていたが，月の情報が0~11で表現されるなどプログラミング言語にありがちな罠もあったので，今はこっちを使っておけば良いように思う。
- `Arc2D.Double`クラスのインスタンスを設定すると円弧（弧）を描くことができるが`setArc()`メソッドの引数が直感的にわかりにくい印象あり。
    - 第1引数，第2引数：弧を描く際のベースとなる円が接する四角形の左上のx座標，ｙ座標の指定
    - 第3引数，第4引数：弧を描く際のベースとなる円が接する四角形の幅と高さ
    - 第5引数:弧の開始時の角度
    - 第6引数:弧の開始時の角度から何度開くかの指定
    - 弧をどのような形で閉じるかの指定
        - Arc2D.PIE：ピザの切れ端みたいな形
        - Arc2D.CHORD：この両端を直線で結ぶ
        - Arc2D.OPEN：開いたままの弧
