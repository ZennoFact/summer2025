## JPanelと描画

描画は基本的に Swingのコンポーネントが持つ`paintComponent`メソッドをオーバーライドして使います。
ただ，paintComponentは引数にGraphicsクラスのインスタンスを取ります。Graphicsクラスにはとても単純な描画処理しかないため，現在はこのGraphicsクラスを拡張したGraphics2Dを使うのがオススメです。

 ## どんなことができるの？

- `public void paintComponent(Graphics g)`
    - 画面描画が必要になって「paintComponent」メソッドが呼ばれる度に描画処理が実行されるので，今回の授業はこれを使おうと心に誓いました。
- `setRenderingHint` はアンチエイリアス処理をかけることができる。品質を優先すると速度が下がるので，このあたりはトレードオフですが，お好みで。
- `setPaint` メソッドで色情報を設定する
    - 設定する色情報はColorクラスのインスタンス
    - GradientPaintクラスでグラデーションを指定することも可能
- `setStroke` メソッドで線の情報を設定する（線を引く前の準備）
    - BasicStrokeクラスのインスタンスで線の太さを指定できる
        - ちなみに線の端っこの形状の指定もできる
- 描く処理は形状を指定してから作業する
    - `draw` メソッドで輪郭を描く
    - `fill` メソッドで塗りつぶす
    - 指定できる形状（クラス）
        - Line2D 線
        - Rectangle2D 四角
        - RoundRectangle2D 角丸の四角
        - Ellipse2D 円（楕円）
        - Arc2D　円弧
        - QuadCurve2D 2次元ペジェ曲線
        - CubicCurve2D 3次元ペジェ曲線
        - Polygon 多角形
- `drawString` メソッドで文字を描く

その他，図形の変形や画像の読み書きもあるので，興味があったら試してみてください。
