### コーディング関連

- `StringBuilder` はString型よりも効率よく文字列を作成するためのもの。Stringクラスは固定の文字列の容量をすぐに確保指定しまい，`+=`演算子での文字列連結をするたびに新しい文字列がポコポコできあがってしまう。StringBuilderなら文字列にするタイミングを任意に決定できるので嬉しい。
なお，StringBuilderはシングルスレッドで，マルチスレッドの`StringBuffer`も有ったりする。

- `java.nio` 　「New I/O」のこと。強そう。もうちょっと真面目に言うと昔からあった`java.io`には問題も色々言われていたので新しく気合い入れて作られたものです。なんかあったらこっちを使ってファイルの入出力をするのがおすすめ。従来のストリームの考え方ではなく，バッファとチャンネルといった概念でI/O処理が実行されます。なお，古いJavaでは動かなかったりするので，java.ioの使い方を知らなくてよいとは言わない。
    - `Path path = Paths.get("ファイルパス");` で処理するファイルを選択
    - `try-catch` の例外処理が必要
    - ファイル全体を取りたいなら `Files.readAllLines(path)` といったやり方が簡単でいいかも
    - 上記のメソッドはList形式で取得される。Listは配列とは異なる複数データの管理方法。Collectionという種類のもので，Java実習２で詳しく学ぶのでお楽しみに。
    - CollecitionはArrayと異なり，`length` ではなく `size()`メソッドで大きさを取得します
- `対象文字列.starsWiths(検査文字列)` 対象の文字列が引数に指定した文字列と一致するかという前方一致に便利なメソッド。これが使えない場合はループで一文字一文字確認するか，文字列を切り出して一致するかというあたりを試すことになる。お察しの通り`endsWith()`メソッドも存在する。
-  `対象文字列.toLowerCase()` 対象の文字列を全て小文字にする。大文字小文字を区別せず何かしたい時などには便利。お察しの通り`toUpperCase()`メソッドも存在する。

### 数学関連

- **三平方の定理** 「ピタゴラスの定理」として知られるが，ピタゴラスが発見したかは確証がないと言われている定理。  2点間の距離を直角三角形を使って計算できるっていう考え方。
なおピタゴラスは古代ギリシアの哲学者と言われてきたが，最近は宗教家と考えられることも増えた。「万物は数なり」とか考えていた人。
- **三角関数** は90度未満の角度を扱う場合，三角関数の値は対応する直角三角形の二編の長さの比。だから三角比と呼ばれたりする。
    - 三角関数は以下の6つがある。
        - sin（sine, 正弦）
        - sec（secant，正割）
        - tan（tangent，正接）
        - cos（cosine，余弦）
        - csc（cosecant，余割）
        - cot（cotangent，余接）
    - 高校までではsin, cos, tan　が有名。
    - ちなみに，三角関数には逆関数が存在する。逆関数は頭に「arc」と付けた関数名が付けられるが，プログラミングでは頭に「a」実装されていることが多い
        - 今回のプログラムでは **atan2**（`Math.atan2`）を使っているけど，これは「2つの引数を取るatan」
        - [Wikipediaにあるatan2のページ](https://ja.wikipedia.org/wiki/Atan2)貼っときます。
    - すっごい雑に説明すると，
        - sin で y座標が出せる（直角三角形の高さだす）
        - cos で x座標が出せる（直角三角形の底辺の長さを出す）
        - tan で 原点からの点の位置が出せる（底辺から高さを出す）
